# 论坛消息中心与私信

消息中心入口为 `/forum/messages/`，位于论坛侧栏最下方。个人中心不再有重复的消息导航；右上角头像进入 `/forum/me/?tab=profile`。侧栏和头像角标统一使用 `dm_unread`，与私信列表中未读消息条数一致，不混入互动和系统通知；`message-summary` 中其他通知计数仍独立保留。

## 升级与配置

部署新代码前执行：

```powershell
npm run forum:migrate
npm run check
npm test
```

迁移只新增私信表和版本记录，不移动或清空现有通知。原 `/forum/notifications/` 会跳转到消息中心的互动或系统通知，并保留回复/互动过滤与页码。

消息页直接展示消息列表，不再区分会话与消息请求，也不显示右上角“发私信”按钮；发起私信从作者区或公开主页进入。

默认启用。需要临时停止发送时，在现有 `data/config.json` 增加 `"messages": {"enabled": false}` 并重启服务。关闭后历史私信仍可读取；新建和发送停止，资料页隐藏发私信入口。配置不包含新增密钥或第三方服务。

## 收发规则

- 作者区、公开个人主页和消息中心可发起私信。搜索成员展示公开昵称、头像与主页，不展示邮箱。
- 打开草稿不建空会话；第一次发送时原子创建会话、两个成员和首条消息。同一对用户只有一个会话。
- 所有用户直接收发，不检查互关，也没有接受、忽略或等待回应限制。旧待回应和已忽略消息保留在普通消息列表。升级移除相关状态列，不删除消息或成员记录。
- 消息为 1–2000 个 Unicode 字符，纯文本渲染。Enter 发送，Shift+Enter 换行；输入法选词不发送。
- 活跃聊天每 2 秒增量轮询，会话列表每 5 秒刷新；非消息页私信角标每 60 秒同步。已读成功后立即刷新列表和角标，统计请求进行中收到的刷新事件会补拉，避免沿用已读前的数量。后台标签页停止轮询，恢复前台补拉。
- 首屏最近 30 条，向上分页；会话列表每批 20 项。读历史时新消息不会强制滚动到最下面。
- 只有前台实际可见的消息推进本人已读游标。互动和系统页的“全部标为已读”只影响对应通知，不清私信未读。
- 单用户每分钟最多发 20 条；不再存在陌生人请求数量限制或首条消息限制。
- 网络失败保留输入和失败气泡，重试沿用同一个请求标识；服务器提交后的显示失败不会把已提交消息标成发送失败。
- 草稿按账号和对端保存在当前浏览器；退出登录时清理。手机聊天采用独立视图，返回恢复会话列表位置。

## 屏蔽、移除与权限

屏蔽用户会停止双方发送，但保留历史；解除只取消自己设置的屏蔽。移除会话只影响自己的列表，新消息到达时会恢复。账号禁言期间禁止发送，仍可阅读、标已读、屏蔽及举报。

所有消息、摘要、游标和举报查询都验证用户身份及成员关系；第三方猜测会话 ID 返回 404。私信页为 noindex，页面和接口使用 no-store。私信正文不进入公共搜索、论坛搜索联想或站点地图。私信不是端到端加密。

## 举报处理闭环

接收者通过消息下方的“举报”提交，之后可在个人中心“我的举报 → 私信”查看；处理开始前可以撤回。发送者不能举报自己的消息。

运营沿用现有命令行工具，增加 `kind=dm`。`actor` 必须是已有管理员或审核员账号。先列队列和领取，领取者才能读该举报前后各最多 5 条消息；证据访问会写审计。不要把证据导出到公开日志或共享文件。

```powershell
# 查看队列（不含私信正文）
npm run forum:moderate -- kind=dm actor=19

# 领取，version 使用队列中当前值
npm run forum:moderate -- kind=dm actor=19 report=4 version=1 action=claim reason="开始核实私信举报"

# 查看本人领取案件的有限证据
npm run forum:moderate -- kind=dm actor=19 report=4

# 成立：隐藏被举报消息并限制作者发言至少 24 小时
npm run forum:moderate -- kind=dm actor=19 report=4 version=2 action=uphold reason="核实骚扰，隐藏消息并限制发言"

# 或不成立
npm run forum:moderate -- kind=dm actor=19 report=4 version=2 action=dismiss reason="核实未违反社区规则"

# 误判恢复：仅管理员，使用当前版本
npm run forum:moderate -- kind=dm actor=19 report=4 version=3 action=restore reason="复核通过，恢复消息"
```

成立/驳回通过系统通知反馈举报人；隐藏和恢复反馈消息作者。恢复时只撤销本次处理施加且未被后续变更的禁言，不清除其他运营动作。屏蔽、发送和处理在会话事务内串行校验；旧版本处理命令被拒绝。

新建表为 `forum_dm_conversations`、`forum_dm_members`、`forum_dm_messages`、`forum_user_blocks`、`forum_dm_reports`。举报使用独立表，因为公开内容举报要求 topic_id。私信举报存在外键，手工维护时须先处理举报再删除其关联数据。

## 验证

`npm run forum:test` 包含私信集成测试，使用带独立标识的临时账号并在结束后清理。只能指向专用测试数据库。测试覆盖直接收发、连续发送、旧请求接口关闭、并发建会话、幂等、屏蔽、权限隔离、举报、处理恢复、分页、开关和限流。群聊、附件、撤回、输入中提示及对方已读回执不属于当前实现。
